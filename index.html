boid vision

vision shape ? the shape of the area each boid can see other boids in; triangles point along the boid's heading.

vision offset ? shifts the vision area along the boid's heading: positive values move it in front of the boid, negative values behind it.

arc width ? only for the arcs vision shape: how many degrees each eye's arc covers, from a narrow slit to a half circle per eye.

arc direction ? only for the arcs vision shape: the angle each eye points away from the heading. 0° merges both arcs into a forward cone, 90° looks sideways like a bird or fish, 180° looks backward.

alignment force

alignment bias ? values greater than 1 cause boids to align more with those facing the same direction, while values lower than 1 cause boids to align more with those facing different directions.
